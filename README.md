# Rajesh Kumar Patra — Portfolio

Dark, premium single-page personal portfolio (static HTML/CSS/JS), visually inspired by the Anshul Tikariha portfolio layout (cyan accents, timeline experience, left social rail). Content is Rajesh Kumar Patra only.

## Contents

| File | Purpose |
|------|---------|
| `index.html` | Page structure and resume content |
| `styles.css` | Dark / cyan styling, timeline, cards |
| `script.js` | Sticky nav, mobile menu, smooth scroll, fade-in |

## How to open locally

1. **Double-click** `index.html`, or
2. From this folder: `xdg-open index.html` (Linux) / `open index.html` (macOS)
3. Optional: VS Code / Cursor **Live Server**

No build step. Keep all three files in the same folder.

**Note:** Google Fonts (Inter) load when online. Offline, system fonts are used.
