## Search Console (SEO)

After the site is live, connect it in Google Search Console:

- Add a property using the URL prefix `https://rk-staging.github.io/portfolio/`
- Verify ownership (HTML tag or GitHub Pages method as prompted)
- Submit the sitemap: `https://rk-staging.github.io/portfolio/sitemap.xml`
- Request indexing for the homepage so Google can discover it sooner
